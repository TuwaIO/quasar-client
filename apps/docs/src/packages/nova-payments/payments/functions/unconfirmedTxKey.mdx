# unconfirmedTxKey()

> **unconfirmedTxKey**(`state`, `checkout`): `string` \| `null`

Defined in: [nova-payments/src/utils/checkout.ts:647](https://github.com/TuwaIO/quasar-client/blob/main/packages/nova-payments/src/utils/checkout.ts#L647)

The transaction the buyer names to the seller about a payment Quasar did not confirm: the one this page handed over
(`txHash`, else `txKey` of the checkout store), else, on a reopened page, the newest one Quasar rejected.

## Parameters

### state

`Pick`\<[`CheckoutState`](?path=/docs/packages-quasar-sdk-checkout-interfaces-checkoutstate--docs), `"txKey"` \| `"txHash"`\>

The state of the checkout store.

### checkout

[`CheckoutView`](?path=/docs/packages-quasar-sdk-checkout-interfaces-checkoutview--docs) \| `null`

What the checkout token opens; `null` until loaded.

## Returns

`string` \| `null`

The transaction hash (EVM) or signature (Solana), or `null` when the page does not know it.
