# isPaidElsewhere()

> **isPaidElsewhere**(`error`): `boolean`

Defined in: [nova-payments/src/utils/checkout.ts:517](https://github.com/TuwaIO/quasar-client/blob/main/packages/nova-payments/src/utils/checkout.ts#L517)

Whether the last error says that Quasar credited the transaction to another invoice of the seller, the one the
wallet that sent it confirmed or whose mark it carries (`tx_already_used` of a transaction that does not pay this
invoice): the buyer names it to the seller if it was the payment of this invoice.

## Parameters

### error

[`CheckoutError`](?path=/docs/packages-quasar-sdk-checkout-interfaces-checkouterror--docs) \| `null` \| `undefined`

The store's error.

## Returns

`boolean`

`true` for a transaction that pays another invoice.
