# groupMethodsByToken()

> **groupMethodsByToken**(`methods`, `walletChainId?`): [`CheckoutTokenGroup`](?path=/docs/packages-nova-payments-payments-interfaces-checkouttokengroup--docs)[]

Defined in: [nova-payments/src/utils/checkout.ts:197](https://github.com/TuwaIO/quasar-client/blob/main/packages/nova-payments/src/utils/checkout.ts#L197)

Groups payment methods by token: the token picked first, then its network. Groups with a
method on the connected wallet's network come first, then those the merchant marks Popular; otherwise the
merchant's order stays.

## Parameters

### methods

[`CheckoutMethod`](?path=/docs/packages-quasar-sdk-checkout-interfaces-checkoutmethod--docs)[]

The methods of the checkout, in the merchant's order.

### walletChainId?

`string` \| `null`

CAIP-2 chain of the connected wallet, if any.
