# PaymentCheckoutClassNames

Defined in: [nova-payments/src/components/customization.ts:36](https://github.com/TuwaIO/quasar-client/blob/main/packages/nova-payments/src/components/customization.ts#L36)

Class name functions of the parts of [PaymentCheckout](?path=/docs/packages-nova-payments-payments-functions-paymentcheckout--docs). Each returns classes added after the default ones of
its part (or nothing), from the state of the checkout and what the part knows; `className` of a replacement
component (`PaymentCheckoutComponents`) gets them too. A color or size a part already sets is changed with the
`--tuwa-*` theme variables of `@tuwaio/nova-core`, or by replacing the part: which of two classes for the same
property wins depends on the order of the stylesheets.
