# PaymentCheckoutComponents

Defined in: [nova-payments/src/components/customization.ts:249](https://github.com/TuwaIO/quasar-client/blob/main/packages/nova-payments/src/components/customization.ts#L249)

Components that replace parts of [PaymentCheckout](?path=/docs/packages-nova-payments-payments-functions-paymentcheckout--docs). A replacement reads the checkout with
[useCheckoutContext](?path=/docs/packages-nova-payments-payments-functions-usecheckoutcontext--docs) (the store, its state, the labels of the checkout language, the connected wallet and the
actions of the steps).
