# RefundStoreOptions

Defined in: [checkout/refundStore.ts:101](https://github.com/TuwaIO/quasar-client/blob/main/packages/quasar-sdk/src/checkout/refundStore.ts#L101)

Options of [createRefundStore](?path=/docs/packages-quasar-sdk-checkout-functions-createrefundstore--docs): the three calls, which the app runs on its server with the secret key. A call refuses by
throwing: the `QuasarSDKError` of the SDK, or from an app's own route an `Error` with the `code` of the refusal, its `status`
and optionally `text`, what to show in the reader's language. A Server Action cannot pass such an error to the browser: wrap it
in [refundAction](?path=/docs/packages-quasar-sdk-checkout-functions-refundaction--docs). Any other error reads as `request_failed`: Quasar did not answer.

### handOverStorage?

> `optional` **handOverStorage?**: [`CheckoutHandOverStorage`](?path=/docs/packages-quasar-sdk-checkout-interfaces-checkouthandoverstorage--docs) \| `null`

Defined in: [checkout/refundStore.ts:117](https://github.com/TuwaIO/quasar-client/blob/main/packages/quasar-sdk/src/checkout/refundStore.ts#L117)

Where a transaction the wallet sent is kept until Quasar takes or refuses it, so that a page closed or reloaded meanwhile
hands it over instead of having the wallet send the refund again. Defaults to the browser's `sessionStorage` (the tab,
until it closes); `null` keeps it in memory only.
