# MetaAddressRecord

Defined in: [checkout/payee.ts:40](https://github.com/TuwaIO/quasar-client/blob/main/packages/quasar-sdk/src/checkout/payee.ts#L40)

A payout wallet's meta-address record (version 2): the keys of the wallet receive the payments of a Quasar app at an
address of their own for each invoice (ERC-5564). Every field is in one canonical form: the signature covers the text
made of them ([metaAddressRecordText](?path=/docs/packages-quasar-sdk-checkout-functions-metaaddressrecordtext--docs)).
