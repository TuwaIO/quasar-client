# PayoutRecord

Defined in: [checkout/payee.ts:20](https://github.com/TuwaIO/quasar-client/blob/main/packages/quasar-sdk/src/checkout/payee.ts#L20)

A receiving wallet's signed word that it takes the payments of a Quasar app on the networks it names. Every field is
in one canonical form: the signature covers the text made of them ([payoutRecordText](?path=/docs/packages-quasar-sdk-checkout-functions-payoutrecordtext--docs)).
