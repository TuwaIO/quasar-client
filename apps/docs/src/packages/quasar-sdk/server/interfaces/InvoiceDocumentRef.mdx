# InvoiceDocumentRef

Defined in: [modules/payments/types.ts:356](https://github.com/TuwaIO/quasar-client/blob/main/packages/quasar-sdk/src/modules/payments/types.ts#L356)

A document issued for an invoice, as [PaymentsModule.listInvoiceDocuments](?path=/docs/packages-quasar-sdk-server-classes-paymentsmodule--docs#listinvoicedocuments) lists it: the invoice, its receipt
or a credit note, in one format. [PaymentsModule.getDocument](?path=/docs/packages-quasar-sdk-server-classes-paymentsmodule--docs#getdocument) downloads the invoice and the receipt,
[PaymentsModule.getCreditNote](?path=/docs/packages-quasar-sdk-server-classes-paymentsmodule--docs#getcreditnote) a credit note by its number or its refund.
