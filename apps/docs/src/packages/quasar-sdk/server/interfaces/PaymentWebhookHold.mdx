# PaymentWebhookHold

Defined in: [webhooks.ts:40](https://github.com/TuwaIO/quasar-client/blob/main/packages/quasar-sdk/src/webhooks.ts#L40)

What a hold is about (`data.hold` of `invoice.held`): an invoice paid in a way that waits for your decision. `reason`
(`late`, `aml`, `quote_expired`), its transaction (`txHash`) and network (`chainId`), the wallets that sent it
(`senders`) and whether it came late (`late`). Release it with [PaymentsModule.releaseInvoice](?path=/docs/packages-quasar-sdk-server-classes-paymentsmodule--docs#releaseinvoice) or refund it; a refund to a wallet AML blocks now
is refused (`sender_blocked`).
