# InvoiceDetails

Defined in: [modules/payments/types.ts:437](https://github.com/TuwaIO/quasar-client/blob/main/packages/quasar-sdk/src/modules/payments/types.ts#L437)

An invoice with its newest refunds and how many refunds and credit notes it has, as
[PaymentsModule.getInvoice](?path=/docs/packages-quasar-sdk-server-classes-paymentsmodule--docs#getinvoice) returns it. It also names what happened to the money, oldest first. Every refund and correction adds a credit note, so the full lists are
[PaymentsModule.listInvoiceRefunds](?path=/docs/packages-quasar-sdk-server-classes-paymentsmodule--docs#listinvoicerefunds) and [PaymentsModule.listInvoiceDocuments](?path=/docs/packages-quasar-sdk-server-classes-paymentsmodule--docs#listinvoicedocuments).
