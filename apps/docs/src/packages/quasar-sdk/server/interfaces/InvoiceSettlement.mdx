Defined in: [modules/payments/types.ts:204](https://github.com/TuwaIO/quasar-client/blob/main/packages/quasar-sdk/src/modules/payments/types.ts#L204)

[InvoiceDetails.payments](?path=/docs/packages-quasar-sdk-server-interfaces-invoicedetails--docs#payments) names them all.
