# WebhookTestEvent

Defined in: [webhooks.ts:214](https://github.com/TuwaIO/quasar-client/blob/main/packages/quasar-sdk/src/webhooks.ts#L214)

The test event an owner or admin of the organization sends to an endpoint from its page in the Quasar dashboard (Send
test event). It is signed and sent like a real event, with its own `sentAt`, so [verifyWebhook](?path=/docs/packages-quasar-sdk-server-functions-verifywebhook--docs) checks it like
any delivery; it is free, tried once and never sent again. Answer it with 2xx and act on nothing: tell it apart with
[isWebhookTestEvent](?path=/docs/packages-quasar-sdk-server-functions-iswebhooktestevent--docs) before reading a body as a payment event or a transaction webhook.
