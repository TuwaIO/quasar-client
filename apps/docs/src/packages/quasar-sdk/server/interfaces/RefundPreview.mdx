# RefundPreview

Defined in: [modules/payments/types.ts:714](https://github.com/TuwaIO/quasar-client/blob/main/packages/quasar-sdk/src/modules/payments/types.ts#L714)

What a refund would send, as [PaymentsModule.previewRefund](?path=/docs/packages-quasar-sdk-server-classes-paymentsmodule--docs#previewrefund) returns it. A requested refund holds its amount until
it is sent, so look before asking: the same amount in the invoice currency sends a different number of tokens once a
volatile asset has moved.
