# QuasarSDKError

Defined in: [core/errors.ts:33](https://github.com/TuwaIO/quasar-client/blob/main/packages/quasar-sdk/src/core/errors.ts#L33)

Error thrown by the methods of the [Quasar](?path=/docs/packages-quasar-sdk-server-classes-quasar--docs) client when a request fails: an HTTP error status, a timeout or a
network error. The Payments API also names the refusal with a stable `code` and, for an invalid request, the fields
at fault (`issues`).

## Example

```typescript
try {
  await quasar.pulsar.getHistory();
} catch (err) {
  if (err instanceof QuasarSDKError) {
    console.error(err.status);        // e.g. 401
    console.error(err.message);       // "[Quasar SDK] Request Failed (401): <error of the API>"
    console.error(err.originalError); // FetchError from ofetch
  }
}
```
